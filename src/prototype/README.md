# 5. Prototype (Прототип)

**Тип:** порождающий паттерн

## Идея
Позволяет **копировать объекты**, не вдаваясь в подробности их реализации. Объект сам умеет создавать свою копию.

## Когда использовать
- Создание объекта дорогое (загрузка из БД, сложные вычисления)
- Нужно много похожих объектов с небольшими отличиями
- Код не должен зависеть от конкретных классов копируемых объектов

## Структура
```
Shape (abstract)
 ├─ copy()                      ← метод клонирования
 ├─ Circle     → new Circle(this)
 └─ Rectangle  → new Rectangle(this)   (глубокая копия списка tags)

ShapeRegistry — хранит готовые прототипы и выдаёт копии
```

## Реализация в проекте
| Файл | Роль |
|------|------|
| `Shape.java` | Базовый прототип с конструктором копирования + `Circle`, `Rectangle` |
| `ShapeRegistry.java` | Реестр прототипов |
| `Main.java` | Демонстрация клонирования |

## Поверхностная vs глубокая копия
В `Rectangle` список `tags` копируется через `new ArrayList<>(...)` — иначе оригинал и клон делили бы один и тот же список.

## Плюсы и минусы
✅ Быстрое создание объектов, меньше повторяющегося кода инициализации
❌ Сложно клонировать объекты с циклическими ссылками

## Запуск
```bash
javac -d out src/prototype/*.java
java -cp out prototype.Main
```
